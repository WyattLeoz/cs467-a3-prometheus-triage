---

* **Prometheus Version:** `<3.8>`
* **OTel Collector Version:** `<0.140>`

### ⚙️ Configuration / Startup

Prometheus is started with the following key flag:

```bash
prometheus --web.enable-otlp-receiver <other relevant flags>
```


The OpenTelemetry Collector is configured to use the otlphttp exporter targeting the Prometheus OTLP endpoint.

All right
